# POC Homiris

Outil de suivi du POC Homiris (prise de RDV télésurveillance en direct par les conseillers).

- Le site est publié par GitHub Pages à partir de `index.html`.
- Les données et les connexions sont gérées par Firebase (projet `poc-homiris`).
- Ce dépôt ne contient aucune donnée ni aucun mot de passe : l'accès est protégé par les règles Firestore.
